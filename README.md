# pangea-news

Pangea News - a multi-category news reader with search and Google sign-in.

Requires a Google OAuth client and a news API key. Copy `.env.example` to `.env.local` and fill it in.

## Stack

- JavaScript
- Next.js
- Chakra UI
- MongoDB
- NextAuth

## Getting started

```bash
npm install
npm run dev
```
